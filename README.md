# 🍄 Mario Treasure Hunt - SENAI Roberto Mange

Um jogo interativo de caça ao tesouro inspirado no universo do Mario, desenvolvido em React.  
O objetivo é explorar o mapa da escola SENAI Roberto Mange, completar desafios e desbloquear novas etapas até encontrar o tesouro final.

---

## 🎮 Sobre o jogo

O jogo utiliza um mapa baseado em uma parte da planta da escola SENAI Roberto Mange, onde cada ponto representa um desafio diferente.

O jogador deve:

- 📍 Explorar os pontos do mapa
- ❓ Responder corretamente as perguntas
- 🔓 Desbloquear o próximo desafio
- 🧩 Resolver frases utilizando palavras em sistema de drag and drop

Cada etapa concluída libera uma nova localização no mapa, criando uma experiência progressiva e interativa.
